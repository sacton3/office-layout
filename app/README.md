# Lab & Offices 3D walkthrough

Open `Lab-and-Offices-Walkthrough.html` (project root) in Chrome/Edge/Firefox. Single self-contained file, no install or internet needed.

Rebuild after editing: `cd app && npm install && node build.mjs` -> `app/dist/office-walkthrough.html`.
Source is in `app/src/` (world.js walls/doors/lights, furniture.js offices/lab/shelving, textures.js, main.js controls/tour/HUD). Dimensions are in feet.
